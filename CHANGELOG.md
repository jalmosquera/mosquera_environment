# Changelog

## v1.0.0 - 2026-09-25

- Instalador reproducible para macOS/Homebrew, Ubuntu/Debian/apt y Arch/pacman.
- Perfiles `core`, `server`, `workstation` y `full`.
- HOME interactiva, simulación y confirmación previa a la instalación.
- `--dry-run`, logs persistentes y backups de configuración antes de reemplazos.
- `doctor` de solo lectura y `update` con fast-forward seguro únicamente.
- Integración de chatsManager como repositorio independiente.
- Hardening de portabilidad, señales, temporales y pruebas fresh-clone Linux.
